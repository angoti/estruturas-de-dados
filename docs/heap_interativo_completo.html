Visualizador interativo de heap: inserção, remoção, sift-up e buildHeap

O novo elemento é inserido no final do array. Depois, o sift-up compara o nó com seu pai repetidamente e sobe enquanto for menor.

pai(i) = ⌊(i − 1) / 2⌋  |  filho esq = 2i+1  |  filho dir = 2i+2
Insira um valor para começar.

A raiz (mínimo) é removida. O último elemento ocupa a raiz. O sift-down desce o nó trocando-o com o menor filho até restaurar a propriedade heap.

Clique em "Remover topo" para iniciar.

BuildHeap parte de um array arbitrário e aplica sift-down de baixo para cima, começando pelo último nó interno ⌊n/2⌋−1. Custo: Θ(n), não O(n log n).

O array inicial está desordenado. Clique para iniciar.

Clique em qualquer nó para ver as relações pai-filho calculadas apenas por aritmética de índice — sem ponteiros, sem memória extra. É isso que permite armazenar o heap em um array simples.

pai = ⌊(i − 1) / 2⌋  ·  filho esquerdo = 2i + 1  ·  filho direito = 2i + 2
